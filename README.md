# Donggyun Seo · 서동균

Undergraduate student in AI Software at Soongsil University.

I am interested in how data and learning processes shape latent representations and model behavior. Drawing on computational social science and complex systems, I am interested in how AI systems represent human knowledge and where their behavior becomes unreliable. More recently, my interests have expanded to LLM safety, particularly jailbreaks, prompt injection, and adversarial evaluation. I seek to understand how model representations and reasoning relate to safety failures, with the goal of developing more interpretable, robust, and trustworthy AI systems.

## Selected Projects

### [Static Security Analyzer for LLM/Agent Applications](https://github.com/SSU-PromptGuard/ai-app-security-scanner)

A Python static analyzer that identifies structural security risks in LLM and agent applications using OWASP LLM risk categories.

**My contribution:** Project lead; Core scanning engine, static analysis.
**Award:** Silver Prize, Soongsil University Software Competition, 2026.

### [FastGainRouter](https://github.com/seo6347/FastGainRouter-SIDL)

An input-adaptive routing method that selects whether to bypass restoration or apply lightweight or stronger restoration models to smartphone images with dirty lenses.

**My contribution:** Independently designed the routing method and conducted implementation, experiments, analysis, and project paper writing.

### [Webtoon Crisis & Recovery](https://github.com/seo6347/webtoon-crisis-recovery)

A data science project examining crises and recovery patterns in webtoons using episode information and reader comments.

**My contribution:** Project lead; Data collection and preprocessing, and the analyses for Research Questions 3 and 4.

### [Disappearing Schools, Declining Communities](https://github.com/seo6347/Disappearing-Schools-Declining-Communities-)

A counterfactual simulation examining how small-school consolidation could affect commuting times and the availability of public elementary schools in rural communities. The initial candidate population includes 2,503 schools.

**My contribution:** Overall analytical design, preprocessing and data integration, analysis implementation, and preparation of the reproducible pipeline.

The current analysis is publicly available; further development is planned for the 2026 Data Journalism Awards.
